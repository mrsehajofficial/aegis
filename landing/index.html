FIELD QUESTIONS // ANSWERED

FREQUENTLY ASKED

Core questions about Aegis — who built it, how it works, and how to deploy it.

Who developed Aegis?

Aegis was created and engineered by Sehaj Varma, an AI Automation Engineer & Backend Developer from India. Source code is open on GitHub.

How does Aegis's anti-flood protection work?

Aegis tracks per-user message frequencies in high-resolution sliding memory windows (e.g. 5 messages / 3000ms). Any flood spike triggers instantaneous restriction before disrupting database queues or group discussions.

What content types can be locked?

Aegis supports 16 granular content locks including voice notes, animated stickers, hyperlinks, media forwards, inline bot queries, and files — per group, without altering admin permissions.

Is Aegis free and open source?

Yes — Aegis is fully open source under the AGPL-3.0 license. Anyone can self-host it for free. The source code is on GitHub at github.com/mrsehajofficial/aegis.

How do I deploy Aegis in production?

Run python -m app.setup for the interactive wizard that provisions the database and creates secure credentials, or use docker compose up --build -d for a fully containerised deployment.

How does Aegis handle data and privacy?

Aegis is self-hosted. Moderation audit logs are stored locally in your own SQLite or PostgreSQL database. Zero tracking telemetry or user chat data is transmitted to any external party.
