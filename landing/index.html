MODULAR DEFENSE MATRIX

ENGINEERED FOR SCALE

Every subsystem is crafted for speed, zero telemetry leakage, and complete group sovereignty.

Sliding-Window Anti-Flood

Tracks per-user message velocity in transient memory. Rapid bursts trigger immediate temporary restriction before channel discussion can be disrupted.

Automated Blacklist Engine

Maintains per-group banned word dictionaries. Messages containing forbidden tokens or malicious tracking parameters are instantly intercepted and removed.

Granular Content Locks

Lock down 16 distinct content classes including audio, video, documents, stickers, links, and forwarded entities without altering admin privileges.

Keyword Notes & Filters

Save instant Markdown-formatted notes and auto-reply filters. Group members retrieve knowledge bases via simple hashtag or command triggers.

Dynamic Welcomes & Rules

Personalized greetings, customizable goodbye acknowledgments, and pinned community bylaws ensure new arrivals integrate seamlessly.

Docker & Systemd Ready

Zero complicated runtime dependencies. Deploy on edge VPS instances with a single Docker Compose command or a resilient native systemd service unit.
